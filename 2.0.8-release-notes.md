# Apocapocket 2.0.8

- New games no longer read the previous character's inventory mapping.
- An explicit load button identifies the selected save even while the default ES3 path is stale. A save without inventory data does not inherit another slot's mapping.
- Missing native objects are retried for up to five seconds after the first restoration attempt. Inventory input waits until restoration finishes. A truly missing item still produces one diagnostic with the slot and save filename.
- Lookup accepts physical child colliders and holstered native weapons without root physics, while keeping stripped icon copies excluded. Exact names, saved positions and ambiguity checks remain in use.
- Existing save keys, mapping version, GUID and configuration are unchanged.

Verified with production-code inventory regressions and native save integration. A replay of the reporting player's save is still needed to establish whether their items were delayed, misidentified, or actually absent from the saved world.
